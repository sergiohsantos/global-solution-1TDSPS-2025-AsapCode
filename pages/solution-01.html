AsapCode CLI · Visão Geral

Menu executável via Python:

- Provisionar nova instância EC2
- Consultar status via Request ID
- Listar últimas requisições da sessão

modo executável via terminal:
$ python3 -m asapcode_cli.py

Opções do Menu:
1 - Criar nova EC2
2 - Checar status de uma solicitação
3 - Listar solicitações desta sessão
4 - Cancelar solicitação (apenas simulado)
5 - Alternar modo (API REAL / SIMULADO)
6 - Sobre o projeto
7 - Sair
