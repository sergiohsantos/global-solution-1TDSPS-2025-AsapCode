FAQ · AsapCode Platform

Como eu provisiono uma instância EC2 real?+
Acesse o menu EC2, clique em “Criar instância”, preencha os campos obrigatórios (nome, região, AMI, tipo, VPC, subnet e security groups) e confirme. O backend FastAPI chama a AWS e a tabela é atualizada via API de status.
Quais recursos são realmente criados em nuvem?+
Apenas EC2 é provisionado de forma real nesta versão. EKS, RDS, IAM e S3 são simulados, mas seguem o mesmo padrão de UX, facilitando a evolução futura da plataforma.
Preciso de servidor para usar o frontend?+
O frontend foi construído para funcionar via file://. Para o fluxo completo de EC2, é necessário apenas subir o backend FastAPI localmente em http://localhost:8000.
O que a AsapCode resolve no contexto do Futuro do Trabalho?+
A plataforma reduz fricção em tarefas de infraestrutura, libera o time para atividades de maior valor e serve como ambiente de prática e requalificação contínua em cloud, automação e boas práticas.
Posso adaptar a plataforma para outros provedores?+
Sim. O design do frontend e o contrato da API foram pensados para serem facilmente estendidos a outros provedores de nuvem, mantendo a experiência de IDP única para o usuário.
