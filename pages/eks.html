Clusters EKS

Esta tela simula o formulário de criação de um cluster EKS semelhante ao console da AWS. Os dados não vão para a nuvem, mas são armazenados localmente no navegador e aparecem no Dashboard central como se fossem recursos reais do catálogo do IDP.

Com este formulário, a AsapCode Platform demonstra como seria o fluxo de provisionamento de um cluster EKS diretamente pelo Developer Portal. No projeto real, esta tela poderia acionar pipelines de automação (Terraform, CloudFormation, CDK, etc.) ou workflows internos.

  • Nome, ambiente e região ajudam a padronizar a nomenclatura multi-conta.
  • A versão do Kubernetes garante alinhamento com o roadmap de upgrades.
  • Node groups gerenciados reduzem o esforço de operação para o time de SRE.
  • O CIDR define o espaço de endereçamento para serviços internos e integrações.

Após clicar em Criar AWS EKS Cluster, o recurso é gravado localmente e passa a aparecer no Dashboard central com o tipo EKS.
